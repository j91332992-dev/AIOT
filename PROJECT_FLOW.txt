================================================================================
                    AIoT 프로젝트 통합 동작 흐름 가이드 (PROJECT_FLOW)
================================================================================

본 문서는 스마트홈(Smart Home) 및 필룸 알약 디스펜서(Pillume) 프로젝트의 구동 방법, 
블루투스 연결, 센서 상호작용 및 전체 시나리오 흐름을 일반 텍스트(TXT) 파일 형식으로 설명합니다.

--------------------------------------------------------------------------------
1. 스마트홈 프로젝트 (Smart Home & Smart Lamp) 동작 흐름
--------------------------------------------------------------------------------

[단계 1: 하드웨어 및 펌웨어 준비]
  - ESP32 보드에 MicroPython을 설치합니다.
  - 's_SmartHome' 폴더 안에 있는 'smartHome.py' 소스코드를 ESP32의 메인(main.py)으로 
    업로드합니다. (ble_library.py 등 통신 라이브러리도 함께 업로드 필수)
  - ESP32의 전원을 켜면, 블루투스가 작동하여 'BLE_LJU'라는 기기명으로 신호(NUS 광고)를 
    송신하기 시작합니다.

[단계 2: 웹 대시보드 실행 및 블루투스 연결]
  - 브라우저를 통해 's_SmartHome/index.html' 파일을 엽니다.
  - 화면 상단의 [블루투스 연결] 버튼을 클릭합니다.
  - 검색된 블루투스 기기 목록 중에서 'BLE_LJU'를 선택하여 페어링(연결)을 완료합니다.

[단계 3: 센서 모니터링 및 실시간 동기화]
  - 기기가 연결되면 ESP32는 DHT11 온습도 센서 및 LDR 조도 센서의 값을 읽어 BLE로 전송합니다.
  - 웹 대시보드의 실시간 대시보드 그래프와 정보 카드가 수신 데이터에 맞춰 실시간으로 갱신됩니다.

[단계 4: 스마트홈 제어 시나리오]
  - LCD 정보 출력: ESP32와 연결된 I2C LCD(16x2) 화면에 온도(temp)와 습도(humi)가 표시됩니다.
  - 조도센서 & 모터 연동:
    * 방 안의 밝기가 어두워지면(LDR 센서값 변화), 스마트 램프(RGB LED)가 자동으로 켜지고 
      서보 모터가 회전하여 블라인드를 닫습니다.
    * 어두워질 때 피에조 부저에서 안내 멜로디가 함께 송출됩니다.
  - 터치 센서 접촉:
    * 4개의 터치 센서핀(touch1 ~ touch4) 중 하나를 터치하면, 특정 소리(부저음)가 나거나 
      OLED 화면의 포차코 캐릭터 동작이 변경되는 로컬 피드백이 일어납니다.

--------------------------------------------------------------------------------
2. 필룸 스마트 알약 디스펜서 프로젝트 (Pillume Smart Dispenser) 동작 흐름
--------------------------------------------------------------------------------

[단계 1: 웹 서버 및 프로그램 구동]
  - [방법 A: Next.js 정식 서버] 
    'Pillume-Stitch-48489-Complete' 폴더 내에서 터미널을 열고 'npm run dev'를 실행하여 
    개발 서버를 켜거나, 'START_PILLUME.bat' 배치 파일을 실행합니다.
  - [방법 B: 단독 실행형 HTML]
    단순 테스트를 원할 경우, 'Pillume-Stitch-48489-Complete/web-standalone/dashboard_base.html' 
    파일을 크롬 등 브라우저에서 바로 열어 구동합니다.

[단계 2: ESP32 디스펜서 준비]
  - 디스펜서 구동 MicroPython 코드인 'micropython/main.py'를 ESP32에 업로드하고 실행합니다.
  - 기기가 켜지면 'ESP_SZ'라는 블루투스 이름으로 페어링 대기 상태가 됩니다.

[단계 3: BLE 연결 및 시간 동기화 (필수)]
  - 웹 대시보드에서 [ESP_SZ 연결] 버튼을 누릅니다.
  - 연결이 성공하는 즉시 웹 브라우저는 '사용자의 현재 시각(시, 분, 초, 날짜)'을 
    ESP32로 전송합니다.
  - ESP32는 수신한 시각을 기준으로 내부 타이머(RTC)를 설정하여, 컴퓨터나 휴대폰과 시간이 
    완벽히 일치하게 됩니다. 이후에는 블루투스가 끊겨도 자체적으로 시간을 계산하여 동작합니다.

[단계 4: 복약 관리 및 IR 센서 배출 작동]
  - 아침, 점심, 저녁 복약 예정 시간이 되면 OLED 화면에 복약 경고(영어)가 출력되고, 
    네오픽셀 LED 무드등이 점등되어 사용자에게 복약 시간임을 알립니다.
  - [알약 배출 조건]: 
    * 사용자가 디스펜서의 알약 배출구 하단에 있는 'IR 적외선 근접 센서'에 손을 갖다 댑니다.
    * 오작동 방지를 위해 센서가 손을 '연속 1초 이상 감지'해야 알약이 배출됩니다.
  - [알약 배출 구동]:
    * 조건이 충족되면 서보 모터가 지정된 슬롯 각도(55도 -> 110도 -> 165도)로 차례로 회전하며 
      알약을 한 칸 떨어뜨립니다.
    * 서보 모터가 회전하여 알약을 떨어뜨리는 동안, 장착된 WS2812B 네오픽셀 LED 스트립에 
      파란색 불빛이 흘러가는 체이싱 효과(Chase)가 표현됩니다.
    * 알약 투하가 끝나면 모터는 0도로 즉시 복귀합니다.

[단계 5: Teachable Machine (인공지능 웹캠) 연동 제어]
  - 웹 대시보드의 카메라 메뉴에서 Teachable Machine 모델을 활성화합니다.
  - 사용자가 웹캠 앞에서 미리 학습시킨 제스처(예: 손들기, 손 내리기 등)를 취합니다.
  - 웹 브라우저가 이미지를 판단해 '불 켜기' 혹은 '불 끄기' 명령을 Web BLE로 ESP32에 전송하고, 
    ESP32는 이에 반응해 WS2812B 네오픽셀 무드등을 켜거나 끕니다.

[단계 6: 밀린 복약(미복용) 경고 및 사이렌 해제]
  - 복약 기한이 넘어가도 사용자가 알약을 받아가지 않으면 '미복용 긴급 상황'으로 전환됩니다.
  - 디스펜서에 달린 피에조 부저에서 큰 사이렌 음이 울리고, LED가 빨간색으로 깜빡입니다.
  - 이 경보는 사용자가 대시보드 화면에 나타나는 [확인했습니다] 버튼을 손으로 누를 때까지 
    멈추지 않고 지속됩니다.

[단계 7: 수동 제어 및 알약 채우기]
  - 약을 디스펜서에 다시 채워야 할 때는 대시보드의 [알약 채우기] 버튼을 누릅니다.
  - 모터가 수동으로 회전하며(55도 -> 110도 -> 165도 -> 0도) 알약을 각 칸에 편하게 넣을 수 
    있도록 배치됩니다.
