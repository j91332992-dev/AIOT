# Pillume — ESP_SZ BLE 스마트 알약 디스펜서

ESP32, 3회전 위치형 알약 디스펜서, IR 근접 센서, WS2812B 및
Teachable Machine 웹을 BLE(저전력 블루투스)로 통합한 프로젝트입니다.
현재 권장 펌웨어는 MicroPython이며 Wi‑Fi, NTP, Arduino 라이브러리를
사용하지 않습니다.

## 현재 확정 구성

| 장치 | ESP32 연결 | 비고 |
|---|---:|---|
| SG90 신호선 | GPIO 13 | 외부 5V 권장 |
| IR 센서 OUT | GPIO 27 | 디지털 출력, 감지 시 LOW |
| 피에조 부저 + | GPIO 23 | 지금은 미연결 가능 |
| WS2812B DIN | GPIO 18 | 기본 8개 |
| OLED SDA | GPIO 21 | SSD1306 128×64 I2C |
| OLED SCL | GPIO 22 | 기본 주소 0x3C |
| 모든 GND | GND 공통 | 외부 5V GND 포함 |

- BLE 장치 이름: `ESP_SZ`
- 회전 위치: 55도 → 110도 → 165도
- 165도 도달 후 30초 대기하고 0도로 원복
- IR 센서에 손이 1초 연속 감지되어야 배출
- 서보 이동 중 WS2812B 파란색 한 칸 체이스
- 웹에서 WS2812B 색상과 밝기(1–100%)를 직접 설정
- 긴급 시 웹의 `확인했습니다`를 누를 때까지 빨간 점멸과 피에조 사이렌 유지
- 웹의 알약 채우기 버튼: 55도 → 110도 → 165도 → 0도 수동 이동
- OLED에 현재 복약 시간대와 미복용 경고를 영어로 표시
- DHT, 조도 센서, 일반 RGB LED, LCD, 터치 센서는 제외
- 피에조가 없어도 나머지 기능은 정상 작동

## BLE 동작 방식

1. ESP32가 `ESP_SZ`라는 이름으로 BLE 광고를 시작합니다.
2. Chrome 또는 Edge에서 대시보드의 `ESP_SZ 연결`을 누릅니다.
3. 브라우저가 현재 시각과 시간대 정보를 ESP32에 전달합니다.
4. ESP32는 브라우저 연결이 끊겨도 전원이 유지되는 동안 자체적으로 시간을
   계산하여 복약 일정을 실행합니다.
5. ESP32를 재부팅하거나 전원을 껐다 켠 뒤에는 안전을 위해 대시보드에 다시
   한 번 연결해야 시간 기반 배출이 활성화됩니다.

Web Bluetooth는 HTTPS 또는 `localhost`에서만 사용할 수 있습니다. Android
Chrome과 PC의 Chrome/Edge 사용을 권장합니다. iPhone/iPad Safari와 Firefox는
Web Bluetooth를 지원하지 않습니다.

## 권장: MicroPython으로 시작하기

1. ESP32에 공식 MicroPython 펌웨어를 설치합니다.
2. Thonny에서 [micropython/main.py](micropython/main.py)를 ESP32
   최상위에 복사합니다. BLE 코드도 이 파일 안에 포함되어 있습니다.
3. ESP32를 재부팅합니다.
4. Shell에서 `[BLE] advertising as ESP_SZ`를 확인합니다.
5. 웹 대시보드의 `ESP_SZ 연결` 버튼을 누릅니다.

자세한 순서는
[MicroPython 설치 안내](micropython/README.md)를 확인하세요. 기존
Arduino 버전은 `firmware` 폴더에 참고용으로 남겨 두었지만, MicroPython
방식을 사용할 때는 `.ino`를 컴파일하지 않아도 됩니다.

웹 실행:

```powershell
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 여세요. 다른 기기에서 웹을 열려면
HTTPS로 서비스해야 Web Bluetooth와 카메라가 정상 작동합니다.

## 복약 시간

| 시간대 | 복약 가능 | 미복용 반복 알림 시작 |
|---|---|---|
| 아침 | 07:00–10:00 | 09:30 |
| 점심 | 11:00–13:00 | 12:30 |
| 저녁 | 15:00–17:00 | 16:30 |

이전 시간대 약을 먹지 않았다면 다음 유효 시간대에 손을 감지했을 때 밀린
회차까지 한 번에 배출합니다. 예를 들어 아침 미복용 상태에서 점심에
감지되면 55도 위치를 거쳐 110도 위치까지 두 번 이동합니다.

## TEST MODE

대시보드 왼쪽 위 `TEST` 버튼에서 모든 주요 기능을 격리된 하드웨어 테스트로
체험할 수 있습니다. 가상 아침·점심·저녁 시간과 복약 시작, 복용 완료,
미복용 경고, 누적 배출, 무드등, 채우기, 긴급상황을 선택할 수 있습니다.

ESP_SZ가 BLE로 연결되어 있으면 서보·네오픽셀·피에조·OLED가 실제로
작동합니다. 단, 테스트 전용 BLE 명령은 복약 기록이나 NVS에 저장되지 않으며
실제 시간표와 IR 자동 감지도 잠시 멈춥니다. 테스트 종료 후 서보 위치와
무드등을 시작 직전 상태로 복원합니다. 테스트 전 알약을 빼고 회전부에서
손을 치워 주세요.

## Teachable Machine

이미지 프로젝트에 `1`, `2`, `3` 클래스를 만들고 모델을 업로드한 뒤,
모델 URL을 대시보드 설정에 입력합니다.

- 클래스 `1`: WS2812B ON
- 클래스 `2`: WS2812B OFF
- 클래스 `3`: 긴급 이벤트 및 팝업, 확인할 때까지 빨간 점멸과 사이렌

클래스 이름은 대시보드 설정에서 바꿀 수 있습니다.
모델에 `Class 1`, `Class 2`, `Class 3`으로 표시되어도 각각 `1`, `2`, `3`과
동일하게 자동 인식합니다.
웹의 무드등 영역에서는 색상 선택기와 밝기 슬라이더로 원하는 색을 설정할
수 있습니다. 약 배출의 파란 체이스가 끝나거나 긴급 팝업의
`확인했습니다`를 눌러 경보를 해제하면 설정한 색상과 밝기로 자동
복귀합니다. 긴급 경보 해제 명령은 BLE로 전달되므로 ESP_SZ가 연결된
상태에서 버튼을 눌러야 합니다.

## 복약 캘린더

웹 상단의 `▦` 캘린더 아이콘을 누르면 날짜별 아침·점심·저녁 복약 기록을
확인할 수 있습니다. React 대시보드는 D1 이벤트 저장소를 사용하고, 단일
HTML 대시보드는 브라우저 로컬 저장소를 사용합니다. ESP32와 웹이 BLE로
연결된 동안 수신된 `DOSE_TAKEN` 기록이 캘린더에 저장됩니다.

## OpenAI AI 챗봇

대시보드 오른쪽 아래의 `AI 챗봇`에서 Pillume 사용법과 오류 해결 방법을
자연어로 질문할 수 있습니다. “아침 약을 먹었는데 기록이 안 됐어”처럼
이미 복용한 기록이 누락된 경우에는 AI가 날짜와 시간대를 확인한 뒤 수동
기록 카드를 제안합니다. 실제 기록은 사용자가 `확인하고 기록`을 눌러야만
저장됩니다. AI는 BLE, 서보, LED, 긴급 경보 또는 설정을 직접 제어하지
않습니다.

개인 PC 프로토타입에서는 AI 챗봇을 처음 열 때 새 OpenAI API 키를
입력합니다. 키는 현재 탭의 메모리에만 유지되며 파일, 소스 코드,
`localStorage`에 저장되지 않습니다. 새로고침하거나 `키 지우기`를 누르면
다시 입력해야 합니다.

배포 환경에서는 브라우저 입력 대신 `.env.example`을 참고하여 서버의
비밀 환경변수에 다음 값을 설정하는 방식을 권장합니다.

```text
OPENAI_API_KEY=
OPENAI_MODEL=gpt-5.6
```

3. `npm run dev`로 실행하고 `http://localhost:3000`에서 사용합니다.

API 키를 `dashboard.html`, React 코드, Git 저장소에 직접 적지 마세요. 단일 HTML
파일을 `file://`로 연 경우 AI 요청은 기본적으로
`http://localhost:3000/api/assistant`를 사용하므로 로컬 서버가 함께 실행
중이어야 합니다. BLE와 나머지 로컬 기능은 AI 키가 없어도 그대로
작동합니다.

ESP32용 Python과 브라우저용 HTML은 실행 환경이 달라 하나의 실행 파일로
합칠 수 없습니다. 최소 구성은 `main.py` 1개와 `dashboard.html` 1개입니다.

## 알약 채우기

디스펜서가 0도일 때 웹의 `알약 채우기` 버튼을 사용합니다.

1. 첫 클릭: 55도로 이동 → 1번 칸에 알약 넣기
2. 두 번째 클릭: 110도로 이동 → 2번 칸에 알약 넣기
3. 세 번째 클릭: 165도로 이동 → 3번 칸에 알약 넣기
4. 네 번째 클릭: 0도로 복귀 → 채우기 완료

채우기 모드 중에는 IR 센서 자동 배출이 잠깁니다. 복약 배출이 진행되어
현재 위치가 0도가 아니면 안전을 위해 채우기 모드를 시작하지 않습니다.

## 안전 주의

SG90과 WS2812B를 ESP32의 3.3V 핀에서 구동하지 마세요. 별도 5V 전원을
사용하고 ESP32 GND와 외부 전원 GND를 공통 연결해야 합니다. 실제 약을
넣기 전에 빈 통 또는 사탕으로 충분히 반복 시험하세요. 이 프로토타입을
의료기기로 간주하거나 생명 유지 목적에 사용하면 안 됩니다.
