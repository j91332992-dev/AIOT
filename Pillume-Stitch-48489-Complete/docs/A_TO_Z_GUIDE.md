# ESP_SZ MicroPython 스마트 알약 디스펜서 A–Z 가이드

현재 권장 버전은 Arduino `.ino`를 컴파일하지 않습니다. ESP32에
MicroPython을 설치한 뒤 BLE 코드까지 포함된 `main.py` 파일 하나만
복사하여 실행합니다. Wi‑Fi, NTP, DHT 및 별도 Arduino 라이브러리는
사용하지 않습니다.

## 1. 전체 시스템

```text
카메라 → Teachable Machine 웹
                  │
                  │ BLE 명령
                  ▼
             ESP_SZ (ESP32)
       ┌──────────┼───────────┐
       ▼          ▼           ▼
   WS2812B      SG90       피에조(선택)
       │                       │
       └──────── OLED ─────────┘
                  ▲
                  │
              IR 근접 센서
```

웹은 ESP32에 현재 시각을 전달하고 모션 명령을 보냅니다. ESP32는 복약 상태와
배출 이벤트를 웹으로 보냅니다. 한 번 시간 동기화한 후에는 브라우저 연결을
끊어도 ESP32 전원이 유지되는 동안 일정이 계속 작동합니다. 재부팅한 뒤에는
안전을 위해 다시 BLE 연결해야 약 배출이 활성화됩니다.

## 2. 준비물

- ESP32 개발 보드
- USB 데이터 케이블
- SG90 서보모터
- 디지털 IR 근접 센서
- WS2812B LED 또는 LED 링
- SSD1306 128×64 I2C OLED
- 외부 5V 2A 이상 전원
- 330Ω 저항
- 브레드보드와 점퍼선
- 3회전 위치형 디스펜서 기구물
- 수동 피에조 부저: 없어도 됨
- PC 프로그램: Thonny

## 3. 핀 연결

| 장치 | 장치 핀 | ESP32/전원 연결 |
|---|---|---|
| SG90 | 신호 | GPIO 13 |
| SG90 | VCC | 외부 5V + |
| SG90 | GND | 외부 5V GND |
| IR 센서 | OUT | GPIO 27 |
| IR 센서 | VCC | 3.3V 권장 |
| IR 센서 | GND | GND |
| WS2812B | DIN | GPIO 18, 중간에 330Ω |
| WS2812B | 5V | 외부 5V + |
| WS2812B | GND | 외부 5V GND |
| 피에조 | + | GPIO 23 |
| 피에조 | - | GND |
| OLED | VCC | ESP32 3.3V |
| OLED | GND | GND |
| OLED | SDA | GPIO 21 |
| OLED | SCL | GPIO 22 |

피에조가 없다면 GPIO 23은 비워 둡니다. 코드 수정은 필요 없습니다.
OLED 기본 I2C 주소는 `0x3C`입니다. OLED가 아직 없다면 네 핀 모두 비워
두어도 나머지 기능은 정상 작동합니다.

서보와 WS2812B를 ESP32의 3.3V 핀에서 구동하면 안 됩니다. 별도 5V를
사용하고 외부 전원 GND와 ESP32 GND를 반드시 공통 연결하세요.

## 4. MicroPython 설치

### 4-1. Thonny 설치

Thonny를 설치하고 ESP32를 USB로 연결합니다.

### 4-2. ESP32에 MicroPython 넣기

1. Thonny를 실행합니다.
2. `실행 → 인터프리터 구성`을 엽니다.
3. 인터프리터를 `MicroPython (ESP32)`로 선택합니다.
4. 올바른 COM 포트를 선택합니다.
5. `Install or update MicroPython`을 누릅니다.
6. 보드 종류는 일반 ESP32라면 `ESP32 / WROOM` 계열을 선택합니다.
7. 최신 안정 버전 펌웨어를 설치합니다.

이 과정은 ESP32의 기존 Arduino 스케치를 지웁니다. 다시 Arduino 방식으로
돌아가고 싶다면 Arduino IDE에서 스케치를 업로드하면 됩니다.

## 5. Python 파일 복사

프로젝트의 다음 파일을 사용합니다.

```text
micropython/
└─ main.py
```

Thonny에서:

1. ESP32에 기존 `ble_library.py`가 있다면 삭제합니다.
2. 새 `main.py`를 엽니다.
3. `파일 → 다른 이름으로 저장`을 선택합니다.
4. `MicroPython device`를 선택합니다.
5. 보드 최상위에 정확히 `main.py`로 저장합니다.

ESP32 내부 파일 구조:

```text
/
└─ main.py
```

BLE 클래스가 `main.py`에 포함되어 있으므로 다른 Python 파일은 필요하지
않습니다.

## 6. 첫 실행

ESP32의 EN/RESET 버튼을 누르거나 Thonny에서 `Ctrl+D`로 소프트 리셋합니다.

정상 출력:

```text
[BLE] advertising as ESP_SZ
[SYSTEM] ESP_SZ MicroPython firmware ready
```

이제 ESP32가 `ESP_SZ`라는 BLE 장치로 검색됩니다. 별도의 Bluetooth
라이브러리를 설치할 필요가 없습니다. MicroPython 펌웨어에 포함된
`bluetooth` 모듈을 사용합니다.

## 7. 웹 실행

프로젝트 폴더에서:

```powershell
npm install
npm run dev
```

PC의 Chrome 또는 Edge에서 아래 주소를 엽니다.

```text
http://localhost:3000
```

Web Bluetooth는 지원 브라우저의 HTTPS 또는 localhost에서만 동작합니다.
Android Chrome도 사용할 수 있습니다. iPhone/iPad Safari와 Firefox는
권장하지 않습니다.

간단하게 사용할 때는 `web-standalone/index.html`을 `dashboard.html`로
복사하고 localhost 또는 HTTPS에서 엽니다. ESP32용 `main.py`와 브라우저용
`dashboard.html`은 서로 다른 장치에서 실행되므로 한 파일로 합칠 수
없으며, 이 두 파일이 최소 구성입니다.

## 8. ESP_SZ 연결

1. ESP32 전원을 켭니다.
2. PC/휴대폰 블루투스를 켭니다.
3. 웹 상단의 `ESP_SZ 연결`을 누릅니다.
4. 장치 선택 창에서 `ESP_SZ`를 선택합니다.
5. 버튼이 `ESP_SZ 연결 해제`로 바뀌는지 확인합니다.
6. 복약 상태와 서보 각도가 화면에 표시되는지 확인합니다.

연결 직후 웹이 현재 Unix 시각과 시간대 정보를 전송합니다. 따라서 ESP32는
Wi‑Fi와 NTP 없이 현재 복약 시간대를 판단할 수 있습니다.

## 9. 하드웨어 설정 변경

[micropython/main.py](../micropython/main.py) 상단에 설정값이 있습니다.

```python
SERVO_PIN = 13
PROXIMITY_PIN = 27
BUZZER_PIN = 23
NEOPIXEL_PIN = 18
NEOPIXEL_COUNT = 8
OLED_SDA_PIN = 21
OLED_SCL_PIN = 22
OLED_I2C_ADDRESS = 0x3C
IR_ACTIVE_LOW = True

DISPENSER_ANGLES = (55, 110, 165)
DISPENSER_SLOT_COUNT = 3
SERVO_MAX_ANGLE = 180
PROXIMITY_HOLD_MS = 1000
RETURN_DELAY_MS = 30000
```

WS2812B 개수가 다르면 `NEOPIXEL_COUNT`를 변경합니다. IR 센서가 손을
감지했을 때 HIGH를 출력한다면 `IR_ACTIVE_LOW = False`로 바꿉니다.

## 10. 복약 시간

| 구분 | 배출 가능 시간 | 미복용 알림 시작 |
|---|---|---|
| 아침 | 07:00–10:00 | 09:30 |
| 점심 | 11:00–13:00 | 12:30 |
| 저녁 | 15:00–17:00 | 16:30 |

복약 시간 시작 시 피에조가 연결되어 있으면 3초간 울립니다. 마감 30분
전까지 복용하지 않으면 5분마다 다시 알립니다.

OLED에는 다음과 같이 영어로 표시됩니다.

| 상태 | OLED 표시 |
|---|---|
| 아침 복약 시간 | `MEDICINE TIME` / `MORNING` / `07AM - 10AM` |
| 점심 복약 시간 | `MEDICINE TIME` / `LUNCH` / `11AM - 01PM` |
| 저녁 복약 시간 | `MEDICINE TIME` / `DINNER` / `03PM - 05PM` |
| 미복용 경고 | `PLEASE TAKE` / `YOUR MEDICINE` / 해당 시간대 |
| 복용 완료 | `MEDICINE TAKEN` / 해당 시간대 |

기존 일정값을 유지했기 때문에 아침은 07:00–10:00으로 표시됩니다. 시간을
바꾸고 싶다면 `MEAL_WINDOWS`와 `MEAL_OLED_RANGES`를 함께 수정합니다.

## 11. 서보 동작

IR 센서에 손이 1초 연속 감지되면 배출하며, 다음 위치로 움직입니다.

```text
0° → 55° → 110° → 165° → 0°
```

165도에 도달하면 30초 기다린 뒤 0도로 원복합니다. ESP32가 165도 상태에서
재부팅되더라도 다시 30초를 기다린 후 0도로 돌아가도록 구현되어 있습니다.
서보가 움직일 때마다 WS2812B의 파란색 빛이 한 칸씩 이동합니다.

처음에는 실제 약 대신 사탕이나 빈 캡슐로 시험하세요.

## 12. 미복용 누적 배출

아침 약을 먹지 않은 상태에서 점심 시간에 손을 대면 아침과 점심 두 회분을
배출합니다.

```text
55° 위치 → 110° 위치
```

아침과 점심을 모두 먹지 않은 상태에서 저녁에 손을 대면 세 회분을 배출하여
총 108도 이동합니다. 남은 물리 칸이 부족하면 배출하지 않고
`REFILL_REQUIRED` 이벤트를 보냅니다.

## 13. Teachable Machine

1. Teachable Machine 이미지 프로젝트를 만듭니다.
2. 클래스 이름을 정확히 `1`, `2`, `3`으로 만듭니다.
3. 다양한 배경과 거리에서 이미지를 수집합니다.
4. 모델을 학습하고 업로드합니다.
5. 웹의 톱니바퀴 설정에 모델 URL을 입력합니다.
6. `ESP_SZ 연결` 후 `모션 인식 시작`을 누릅니다.

- 클래스 `1`: WS2812B ON
- 클래스 `2`: WS2812B OFF
- 클래스 `3`: 긴급 팝업, 빨간색 빠른 점멸, 피에조 사이렌

예측 확률 85% 이상이 5프레임 연속 유지될 때 BLE 명령을 전송합니다.
Teachable Machine이 이름을 `Class 1`, `Class 2`, `Class 3`으로 내보내도
웹에서 앞의 `Class`를 제거해 숫자 `1`, `2`, `3`과 동일하게 처리합니다.

## 14. 웹 LED 색상·밝기 조절

대시보드의 `제스처 무드등` 또는 단일 HTML의 `수동 기능 시험`에서 다음
항목을 조절합니다.

1. 색상 칸을 눌러 원하는 LED 색을 고릅니다.
2. 밝기 슬라이더를 1–100% 사이로 맞춥니다.
3. `적용하고 켜기` 또는 `색상·밝기 적용`을 누릅니다.
4. `끄기`를 누르면 현재 설정을 보존한 채 LED만 꺼집니다.
5. 클래스 `1` 동작으로 다시 켜면 마지막에 지정한 색상과 밝기가 적용됩니다.

서보가 움직이는 동안에는 파란색 체이스가, 긴급상황에는 빨간색 점멸이
안전 표시로 우선합니다. 긴급 경보는 시간으로 자동 종료되지 않습니다.
웹 긴급 팝업의 `확인했습니다`를 눌러 ESP32가 해제 명령을 받은 뒤에만
빨간 점멸과 사이렌이 멈추고 사용자가 지정한 무드등 색상과 밝기로
복귀합니다. 따라서 경보를 끄려면 웹과 ESP_SZ의 BLE 연결이 필요합니다.
여기서 밝기는 WS2812B 출력 밝기이며, 조도 센서의 측정값과는 관계없습니다.

## 15. 알약 채우기 모드

웹의 `알약 채우기` 영역은 세 칸을 수동으로 채울 때 사용합니다.

| 버튼 클릭 | 서보 위치 | 작업 |
|---:|---:|---|
| 1회 | 55도 | 1번 칸에 알약 넣기 |
| 2회 | 110도 | 2번 칸에 알약 넣기 |
| 3회 | 165도 | 3번 칸에 알약 넣기 |
| 4회 | 0도 | 채우기 완료 |

버튼을 한 번 누른 뒤 서보와 파란 LED 동작이 끝날 때까지 기다리고 알약을
넣은 다음 다시 누릅니다. 채우기 모드가 활성화된 동안 IR 센서 감지는
자동 배출로 이어지지 않습니다. 기존 배출 때문에 디스펜서 위치가 0도가
아니면 먼저 정상 원복을 기다려야 채우기를 시작할 수 있습니다.

## 16. 복약 캘린더

웹 상단의 `▦` 아이콘을 누르면 월별 복약 캘린더가 열립니다. 각 날짜의
`아`, `점`, `저` 원이 초록색이면 해당 아침·점심·저녁 약을 복용한
것입니다.

React 대시보드는 D1 이벤트 저장소에서 최대 500건을 조회합니다. 단일
`dashboard.html`은 브라우저 로컬 저장소에 최대 1000건을 보관합니다.
ESP32와 웹이 연결되지 않은 동안에는 BLE 이벤트를 웹이 받을 수 없으므로
그 시간의 과거 기록은 캘린더에 자동 추가되지 않습니다.

## 17. 상태 보존

복약 완료 비트와 현재 디스펜서 칸은 ESP32 NVS에 저장됩니다. 전원이
꺼졌다 켜져도 유지됩니다. 날짜가 바뀐 것을 시간 동기화 후 확인하면
아침·점심·저녁 복약 기록을 새로 시작합니다.

시간 자체는 저장하지 않습니다. 재부팅 후 오래된 시각으로 잘못 배출하는
것을 막기 위해 웹에 다시 연결하기 전에는 IR 센서 배출을 차단합니다.

## 18. 문제 해결

### `BLESimplePeripheral`에 `send_status`가 없다고 나옴

예전 `main.py` 또는 `ble_library.py`가 실행 중인 상태입니다. 보드의 기존
`main.py`와 `ble_library.py`를 삭제하고 새 단일 `main.py`만 저장한 다음,
반드시 EN/RESET 버튼을 누르거나 전원을 껐다 켜세요.

### `ImportError: no module named bluetooth`

일반 Python을 ESP32에서 실행한 것이 아니거나 잘못된 펌웨어입니다.
공식 ESP32용 MicroPython 펌웨어를 다시 설치하세요.

### ESP_SZ가 검색되지 않음

- Thonny Shell에 `[BLE] advertising as ESP_SZ`가 나오는지 확인
- 다른 기기가 이미 연결되어 있으면 연결 해제
- ESP32 RESET 후 다시 검색
- PC/휴대폰 블루투스 확인

### 서보가 움직일 때 ESP32 재부팅

- 서보 전원을 ESP32 3.3V에서 분리
- 외부 5V 2A 이상 전원 사용
- ESP32와 외부 전원 GND 공통 연결

### IR 센서가 반대로 작동

- 센서 가변저항으로 감지 거리 조절
- `IR_ACTIVE_LOW` 값을 반대로 변경
- OUT 전압이 3.3V인지 확인

### 피에조가 없음

그대로 사용하면 됩니다. 나중에 전원을 끄고 `+`를 GPIO 23, `-`를 GND에
연결하면 기존 Python 코드를 수정하지 않아도 작동합니다.

### OLED가 켜지지 않음

- VCC가 3.3V, GND가 공통 GND인지 확인
- SDA가 GPIO 21, SCL이 GPIO 22인지 확인
- 흔한 주소는 `0x3C`이지만 모듈이 `0x3D`라면
  `OLED_I2C_ADDRESS = 0x3D`로 변경
- OLED가 없어도 Shell의 `[OLED] not detected` 메시지만 나오며 다른 기능은
  계속 작동

## 19. 최종 확인표

- [ ] 새 단일 `main.py`가 ESP32 최상위에 있다.
- [ ] 예전 `ble_library.py`는 삭제했다.
- [ ] Shell에 `advertising as ESP_SZ`가 표시된다.
- [ ] 웹에서 ESP_SZ 선택과 시간 동기화가 성공한다.
- [ ] IR 센서에 손을 1초 유지해야 배출된다.
- [ ] 서보가 55도, 110도, 165도 순서로 이동한다.
- [ ] 서보 이동 중 파란 LED가 한 칸씩 움직인다.
- [ ] 웹에서 선택한 LED 색상과 밝기가 즉시 적용된다.
- [ ] 파란 체이스·빨간 긴급 점멸 후 설정한 무드등 색으로 복귀한다.
- [ ] 같은 시간대에 중복 배출하지 않는다.

## 20. AI 도우미 사용

오른쪽 아래 `AI 도우미`를 열고 새 OpenAI API 키를 입력하면 Pillume
기능과 오류 해결 방법을 자연어로 질문할 수 있습니다. 키는 현재 탭의
메모리에만 유지되고 파일이나 `localStorage`에는 저장되지 않습니다.

AI 서버가 필요하므로 전체 소스 폴더에서 `npm install` 후
`npm run dev`를 실행하고 `http://localhost:3000`으로 접속하세요. 누락된
복약 기록은 AI가 확인 카드를 제안할 수 있지만, 사용자가
`확인하고 기록`을 눌러야 저장됩니다. AI는 하드웨어와 시스템 설정을 직접
변경하지 않습니다.

실제 복약용으로 쓰기 전에는 빈 통이나 대체 물체로 여러 날 반복 시험하세요.
이 프로젝트는 의료기기나 생명 유지 장비가 아닙니다.
